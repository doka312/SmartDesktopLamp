# Скриншоты для страницы установки

Положите сюда файлы с этими именами, и сайт покажет их вместо заглушек.
Пока файла нет, на его месте видна заглушка «Место для…».

| Файл          | Что на нём                                                         | Форма                         |
|---------------|--------------------------------------------------------------------|-------------------------------|
| `hero.jpg`    | Фото лампы для шапки сайта: на тумбочке у кровати, красиво освещает комнату | горизонтальная, **4:3** (например, 1600×1200) |
| `palette.png` | Экран лампы в «Доме» с палитрой: где найти плитки цветов           | любая, растягивается по ширине |
| `tile-1.png`  | Плитка 1 (H 352°, S 3%): какую нажать для первого эффекта         | вертикальная, примерно 3:4    |
| `tile-2.png`  | Плитка 2 (H 9°, S 5%)                                              | вертикальная, примерно 3:4    |
| `tile-3.png`  | Плитка 3 (H 17°, S 7%)                                             | вертикальная, примерно 3:4    |

Удобно обвести нужную плитку кружком прямо на скриншоте.
Фото для шапки лучше сжать до 300–500 КБ (например, через squoosh.app), чтобы страница открывалась быстро.

Если захотите другие имена или формат, поменяйте пути
в `docs/app.js` (массив `TRIGGER_SLOTS`) и в `docs/index.html` (`img/hero.jpg`, `img/palette.png`).
