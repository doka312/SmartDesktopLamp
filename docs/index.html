Smart Desktop Lamp

Умная настольная лампа

Установка за пять минут, прямо в браузере

Выберите, какой будет ваша лампа, укажите Wi‑Fi и нажмите одну кнопку. Программы устанавливать не нужно, достаточно USB‑кабеля.

  • ⏱ около 5 минут
  • 🔌 USB‑кабель
  • 🏠 приложение «Дом»
Этот браузер не умеет работать с USB. Откройте страницу на компьютере в Google Chrome или Microsoft Edge. Safari, Firefox и телефоны пока не подходят.
Лампа уже настроена раньше?

Подключите её по USB, и мы подставим текущие настройки, чтобы вы поменяли только нужное.

1

Какой будет ваша лампа

Режим можно поменять в любой момент, снова зайдя на эту страницу.

3 – 64
2

Эффекты

В приложении «Дом» у лампы есть готовые плитки с цветами. Три из них мы превратим в «кнопки» эффектов: нажали плитку, и заиграла анимация.

Вы выбрали базовую лампу, эффектов в ней нет. Эти плитки будут просто включать свой цвет.

3

Домашний Wi‑Fi

Лампа подключается к Wi‑Fi, чтобы iPhone мог ею управлять.

Лампа уже подключена к сети . Оставьте поля пустыми, чтобы ничего не менять.

📶

Лампа работает только с сетью 2,4 ГГц. Если роутер раздаёт две сети, выберите ту, в названии которой нет «5G».

🔒

Пароль уходит прямо в лампу по кабелю. Эта страница его никуда не отправляет и не сохраняет.

4

Код для приложения «Дом»

Восемь цифр, которые iPhone попросит при добавлении лампы. Это как пароль для первой встречи.

— — —

Apple не принимает слишком простые коды: восемь одинаковых цифр, 12345678 и 87654321. Запишите код, а в конце мы покажем его ещё раз вместе с QR‑кодом.

5

Установка

Проверяем, какая прошивка доступна…

  1. Подключите лампу к компьютеру USB‑кабелем. Кабель должен передавать данные: некоторые кабели от зарядок умеют только заряжать.
  2. Нажмите большую кнопку ниже. Браузер покажет окно со списком: выберите в нём USB JTAG/serial debug unit (или похожее) и нажмите «Подключиться».
  3. Не отключайте кабель, пока не появится надпись «Готово».
